# Feature security Enhancments
This feaure set should move our security enabler forward to be uses by the wiki platform. It encapsulates the following features
 
 - Login to user strong passwords for password updates etc
 - An admin screen that allows the backend user to add users and assign roles
 - An ability to create an invitations system
 - Ability to login a user from an email address for sysems that already manage the authentication e.g. Teams and Chrome Extension
 - User Profile management apis and scripts

## Login to user strong passwords for password updates etc
What I would like to do here is to update the registration screen to offer a unique strong password or if the customer wants to add their own we have a strong password validator.

## An admin screen that allows the backend user to add users and assign role
I would like in the authentication service to have a user management screen that allows an admin to see list users, be able to edit (details, roles) and create users. There should be a role admin screen where roles can be created and a users screen where a users details can be update and assigned rolls
I would also like to be able to upload a csv file that allows me to create and update users.

## An ability to create an invitations system
I would like to create an invite system that is made up of the following components. I would like to, like the register screen, to have a request invitation screen. This allows a user to capture their name, email, mobile number or enter an invitation number. This then creates an entry in a security invitations table with a unique invitation code. The admin user should be able to approve the invitation and when the user comes back and enters the invitation code then the user is forced to capture their strong password and are then active users. Note that then the invitation should be marked as used and not be able to be used again. The user will now be create/marked as active using the invitation details and captured username and password
 
## Ability to login a user from an email address for sysems that already manage the authentication e.g. Teams and Chrome Extension. 
Ok so this is a complex one, I want a way to be able to autenticate the user by just passing the email address and then getting the normal login autheitcated cookie status. This will not be an API but a redirect so it is secure. 

## User Profile management apis and scripts 
Ok, now I would like a UI scripts page that allow the logged in user to change their password and create/delete a secure token for using the APIS. This token should then be able to be used to call any API's.
