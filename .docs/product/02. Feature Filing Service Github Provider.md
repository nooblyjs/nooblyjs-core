# Feature Filing Service Git Provider
The knowledge repository will be using bitbcket to store its content so I would like to make the github provider production ready.
I would like the following features to be implemented

 - Git clone should there not be any repo
 - Periodic commits and pushes to the repo with a defined commit message
 - Periodic pulls from the repo to keep us updated with a good conflict strategy


# Feature Git clone should there not be any repo
Should the application startup and the cloned repository not be found then the application should clone the repository.

# Feature Git clone should there not be any repo
The application should periodically (configured in settings) commit and push to repository using a commit message specified in the settings.
